# v1 基线图 · 2026-06-11

这四张图是 ChaoticNet 项目仿真阶段的第一组基线产物，存档保留，避免后续重跑 visualize.py 被覆盖。

## 文件清单

| 图 | 内容 | 用途 |
|---|---|---|
| fig_single_trial_000.png | 单次仿真四联图（θ-t / xy 轨迹 / 相空间 / 能量漂移） | 给队友/导师看"仿真长啥样" |
| fig_butterfly.png | 蝴蝶效应：两条差 0.1° 的轨迹对比 + log 偏差 | 答辩/论文的混沌敏感性招牌图 |
| fig_energy_sweep.png | 50 组能量漂移直方图 + 初值散点 | 论文方法章节，证明求解器精度 |
| fig_phase_grid.png | 12 组不同初值的相空间形态对比 | 看混沌轨迹多样性 |

## 参数（来自 sim/baseline.py v1.0）

- L₁=250mm, L₂=200mm
- m₁=25g, m₂=66g (P03 v2.1 45# 钢盘)
- g=9.81 m/s²
- RK45, rtol=1e-10, atol=1e-12
- 30s @ 120fps
