## 用什么软件改

- **直接看 / 投到论文里**：任何浏览器 / Preview / VSCode 都行；插入 LaTeX 用 `\includegraphics` 即可（`pdflatex` 不直接吃 SVG，先 `rsvg-convert -f pdf in.svg -o out.pdf` 或 `cairosvg` 转 PDF）。
- **想可视化拖拽编辑**：Sketch、Figma 都能开 SVG；专业的用 **Inkscape**（免费、Mac 上 `brew install inkscape`）。
- **代码改**：纯文本 SVG，用 VSCode/Sublime 编辑 XML 标签即可。

## 关键设计理由（评委可能问）

### 为什么 L₁=250、L₂=200（非对称）

- 双摆对称（L₁=L₂）时存在退化对称模态，混沌窗口更窄；非对称比例（L₁ > L₂ × 1.25）能在更宽初值范围内进入完整混沌。
- 选 250/200 是手机相机视场 1m 距离下能完整框入的尺寸，再大相机要拉远。

### 为什么用 MR105ZZ 而不是更便宜的塑料套筒

- 衰减时间常数（自由摆动后摆幅减半所需时间）是关键工程指标。塑料/铜套筒摩擦大，τ < 10s，意味着真正混沌阶段不到 5 秒就被摩擦吃掉。
- MR105ZZ + 钟表油，目标 τ ≥ 30s（实测待单摆衰减测试补），留出足够的"干净"混沌窗口给 AI 训练数据。
- 选 5mm 内孔是为了配合 M3 螺栓和摆臂厚度公差。

### 为什么是 ±0.5° 而不是更高精度

- 半导体激光 + CCD 行扫描能做到 ±0.05°，但需要 1.5 万元的传感器。
- 初值状态由视频反演、估计不确定度约 ±0.5°，工程级足够——这本身就是论文要论证的：**"在普通本科实验室条件下 AI 预测的可用边界"**。（注：装置用手动释放，不依赖精确释放机构；模型吃的初值是从视频量出来的。）
- 5.4 章会做初值精度敏感性扫描（1e-1 到 1e-5 扰动），用真实精度去映射预测可靠窗口，这才是有研究价值的事情。

### 为什么相机 60fps 就够

- 双摆固有频率 ω₀ ≈ √(g/L) ≈ 6.3 rad/s ≈ 1 Hz，混沌阶段瞬时角速度峰值 ~20 rad/s。
- 60 fps 的 Nyquist 上限是 30 Hz，对 20 rad/s ≈ 3.2 Hz 的运动有 ~19× 过采样，足够无混叠重建。
- 更高帧率多出来的精度被相机抖动和荧光点定位精度抵消，没有实际收益但数据量翻倍。
- 真实数据集 29 段统一用 1080p@60fps；几乎所有近 3 年的手机都支持，多数也支持 120fps 慢动作（仅早期测试用过，未纳入数据集）。仿真内部采样用 120fps，是数值选择、与相机无关。

### 为什么背板是哑光黑亚克力

- 视觉追踪管线第一步是颜色阈值分割，反光红荧光点在哑光黑背板上的 RGB 分离度最大。
- 哑光（不是亮面黑）防止 LED 直射反光形成假"红点"。
- 亚克力比黑纸耐用，不会因为摆动气流变形。
