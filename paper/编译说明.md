# ChaoticNet 论文编译说明

## 环境要求

需要 **TeX Live 2024+**（含 ctex 宏包和 biblatex/biber）。Mac 上推荐：

```bash
brew install --cask mactex          # 完整版（推荐，~5GB）
# 或
brew install --cask basictex        # 精简版，需要手动补包
```

精简版补包：

```bash
sudo tlmgr update --self
sudo tlmgr install ctex biblatex biber physics cleveref booktabs \
                   subcaption algorithm algorithmicx
```

## 编译命令

中文论文必须用 `xelatex`，不能用 `pdflatex`：

```bash
cd paper
export TEXINPUTS="./texstyles/gb7714//:"
xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex                    # 跑两遍交叉引用稳定
```

或者用 `latexmk` 一键搞定：

```bash
TEXINPUTS="./texstyles/gb7714//:" latexmk -xelatex main.tex
```

### ⚠️ 漏掉 TEXINPUTS 会导致 xelatex 死循环

`TEXINPUTS` 不是可选项。缺了它，biblatex 找不到随项目附带的 `gb7714-2015` 样式，
`\supercite` 便不会被定义；而导言区第 48 行有 `\let\cite\supercite`，
于是 `\cite` → 未定义的 `\supercite` → 回退调用 `\cite`，构成无限递归。
`-interaction=nonstopmode` 下 xelatex 不会停，而是持续把同一条警告刷进日志——
实测可在几分钟内把 `main.log` 撑到数 GB，把磁盘写满。

识别方法：日志里反复出现

```
Package biblatex Warning: '\supercite' not defined by citation style.
(biblatex)                Falling back to '\cite' on input line 188.
```

处置：立即 `pkill xelatex`、删掉巨型日志，补上 `TEXINPUTS` 重编。
批量或自动化编译时建议加 `ulimit -f 200000`（约 100 MB）给日志上闸。

### biber 静默失败（bbl 为空、引用全部未定义）

若 `biber` 退出码非 0、`main.bbl` 为 0 字节、正文引用全变成 `[?]`，
而 `main.blg` 里只有 INFO 没有报错，通常是 biber 的 PAR 缓存损坏（磁盘写满后尤其容易）。
清掉缓存即可恢复：

```bash
rm -rf "$(biber --cache)"
```

`texstyles/gb7714/`，因此编译时需保留上面的 `TEXINPUTS` 环境变量。文献库已收核心条目：

- 双摆动力学：Shinbrot 1992
- ESN：Jaeger 2004、Pathak 2018
- PINN：Raissi 2019、Greydanus 2019（HNN）、Cranmer 2020（LNN）
- 混沌教材：Ott 2002
